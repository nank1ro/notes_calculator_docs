On desktop, the web and tablets, each note opens in its own tab. On phones,
the app opens on your notes list and each note opens as its own page (see
[On phones](#on-phones)). New users start with a short sample note that shows
what Notes Calculator can do.

A note is named after its heading: start a new note with `# Trip budget` and
it is called Trip budget. To rename a note yourself, double-click its tab on
desktop, or tap its title on a phone.

## The tab menu

The tab menu has the actions for one note: closing tabs, **Export** and
**Share link** (see [Sharing a Note as a Link](/features/sharing/)), and
**Delete**.

- **Desktop and web:** right-click a tab.
- **iOS and Android tablets:** long-press a tab.

## On phones

A phone is an iPhone or Android phone, or a phone's browser using the web
app. Tablets and computers keep tabs.

The notes list is the home screen. Tap a note to open it as its own page,
with **Back** to return to the list, the note's title, and a **⋯** menu with
**New note**, **Rename**, **Find in note**, **Share link**, **Export**,
**Settings**, **Documentation** and **Delete**. If you left a note open, it
opens again when you come back to the app.

Each note in the list has a **⋯** menu too, with **Share link**, **Export**
and **Delete**. Long-press a note to open the same menu, or swipe it to the
left to delete it. You're asked to confirm before a note is deleted.

## Note lists

All your notes are listed in **Search Buffer** on desktop and web
(**Cmd/Ctrl + P**, or the search icon), in the **Notes** tab on iOS and
Android tablets, and on the notes list on phones.

The most recently updated notes are on top. Under each title you see when the
note was last updated and when it was created, for example
"Updated 5 minutes ago | Created Oct 1, 2026". When both read the same, as
for a note that was never edited, only "Updated" is shown.

Dates from the last week read like "2 days ago"; older ones show the date
itself. With **Use European date format** on, dates read day first, like
"1 Oct 2026".
